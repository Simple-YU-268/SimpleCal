# SimpleCal
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
People planning personal events and tasks in a self-hosted calendar. Existing repository audience; broader audience research remains open.

## Product Purpose
Plan events in a month-first calendar, with a task list on the right. This default workspace was confirmed by the user.

## Stack
Existing Node ESM backend and vanilla JavaScript/Vite frontend. Preserve calendar data, DAV compatibility, account security and existing CRUD behavior.

## Brand Commitments
The latest user decision supersedes the earlier mint palette: use deep indigo `#3B54C4` with the V2 colour-carried calendar treatment. Preserve saved calendar colors and explicit accent preferences.
Independent SimpleCal identity and original logo. The user requests a fresh, bright palette using #3B54C4, #BEEFEA, #FFD94D, #FFC7DE and #B7D6F7; TickTick-like hierarchy and Apple Liquid Glass-inspired material. Soft enlargement when opening tasks, smooth transitions, immersive but readable interaction. Source acknowledgements and legally necessary notices remain in the repository, not in everyday product UI.

## Product Principles
- Calendar first, tasks within reach.
- Readable information before visual effects.
- Preserve keyboard access, reduced-motion preferences, mobile use and dark mode.
- Keep user data and existing account settings intact during the redesign.

## Evidence on Hand
Existing application, 118 frontend test files, protocol tests, self-hosted runtime and synthetic test content. No real customer data is needed for previews.
