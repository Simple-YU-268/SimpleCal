# SimpleCal 0.5.0

发布日期：2026-11-03。

- 重新整理桌面日历工作区、任务面板与日期层级，保留深浅主题和自定义强调色。
- 设置页采用桌面左侧分类，优化手机色块布局；统一弹窗与事件编辑器的间距、边界和焦点。
- 设置分类支持上下方向键，隐藏取色器不再产生不可见的键盘停靠点。
- 修复 UTC 与具名时区重复事件的夏令时偏移，保留排除日期、单次改期和导出回读语义。
- 修复 CalDAV 全天事件的日期偏移、排他结束日期及实例标识；接受常见客户端的域后缀 UID。
- 新增真实后端与 tsdav 双向读写验收、共享日期语料及独立前端树构建检查。

日期严格验收通过；参考库 ical.js 的三项闰日差异保留 TODO，不计为兼容通过。
Apple Calendar、Thunderbird、DAVx5 和 Google Calendar 的真实客户端界面验证仍待确认。

发行附件为通用服务器运行包与 SHA-256 校验文件，不发布 fnOS 专用安装包。
Docker 用户使用源码构建镜像；生产升级保留 Compose 配置与数据卷，使用
`deploy/upgrade.sh` 构建、检查版本、切换服务，健康检查失败自动回滚。

发布验证：前端 122 个测试文件通过（1520 项通过、1 项既有跳过），浏览器端到端
16 项通过，后端部署与 DAV 等相关回归 15 项通过。日期严格基线 164 项通过、
3 项参考库 TODO；国际化、生命周期、图标与零云依赖静态审计通过。
